5분 발표 화면 · Image2Trailer AI Scene Director

이미지 한 장을 영화 예고편 패키지로 변환하는 라이브 생성 파이프라인

객체 탐지, 멀티모달 장면 연출, 포스터 생성, 한국어/영어 음성 합성을 하나의 Gradio 데모로 묶었습니다. 발표 중에는 미리 생성된 결과를 보여주며 “각 모델이 어떤 입력을 받아 어떤 출력을 만드는가”를 설명합니다.

입력: 이미지 1장 출력: 분석 · 제목 · 대본 · 포스터 · 음성 언어: 한국어/영어 선택 음성: 내 목소리 클론/기본 목소리 선택 GPU: RTX 5090, CUDA_VISIBLE_DEVICES=3

실제 산출물 예시

발표 중 실제 데모 화면은 별도로 띄워두고, 이 발표 화면은 전체 구조와 핵심 메시지를 고정해서 설명하는 용도입니다.

End-to-End 생성 흐름

각 단계는 명확한 입력/출력을 갖고, 실패 시 fallback 상태를 UI에 표시합니다.

목표: 2-3분 내 결과 확인
1

Object Detection

사용자가 입력한 탐지 쿼리를 기준으로 장면 단서를 찾고 박스 이미지를 만든다.

Grounding DINO
2

Scene Director

원본 이미지와 탐지 객체를 근거로 장면 분석, 장르, 제목, 로그라인, 대본을 JSON으로 생성한다.

google/gemma-4-12B-it
3

Poster Generation

Gemma의 포스터 프롬프트와 제목을 받아 영화 포스터를 직접 생성한다. 텍스트 오버레이 후처리는 제거했다.

Tongyi-MAI/Z-Image-Turbo
4

Voice Narration

선택한 언어의 내레이션을 WAV로 합성한다. 클론 선택 시 미리 올린 목소리 샘플을 참조한다.

Qwen3-TTS Base / CustomVoice
5

Gradio Output

박스 이미지, 객체 리스트, 텍스트 결과, 포스터, 오디오, 단계별 상태를 한 화면에 보여준다.

src/ui.py · run_pipeline()
출력 언어한국어 모드와 영어 모드를 선택한다. Gemma 텍스트와 TTS language가 함께 바뀐다.
음성 모드내 목소리 클론 또는 기본 목소리 중 선택한다.
포스터 방식Z-Image가 제목 포함 포스터를 직접 생성한다. PIL 텍스트 후처리는 사용하지 않는다.
현장 안정성각 adapter 실패 시 fallback status를 반환해 발표 흐름이 끊기지 않게 한다.

기술적으로 보여줄 점

  • 하나의 이미지가 단계별 구조화 데이터로 바뀌며, 각 모델의 역할이 분리되어 있다.
  • Gemma는 창작 결과를 JSON 계약으로 반환해 Poster/TTS/UI가 그대로 소비한다.
  • TTS는 별도 `.venv_tts` subprocess에서 실행되어 Gemma와 dependency 충돌을 피한다.
  • 언어 선택과 음성 선택이 데모 흐름 안에서 조합 가능하다.
