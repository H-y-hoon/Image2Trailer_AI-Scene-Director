아키텍처

한 결과 계약을 유지하고, 네 개 모델 단계를 독립 어댑터로 교체합니다.

Detector

Grounding DINO

open-vocabulary 객체와 영화적 단서를 찾고 bounding box 이미지를 만듭니다.

Director

Gemma 4 12B IT

이미지와 탐지 결과를 받아 장면 분석, 장르, 제목, 대본, 포스터 프롬프트를 생성합니다.

Poster

Fast Diffusion

기본은 Z-Image-Turbo/Lightning류, 시간이 남으면 Z-Image-Turbo를 붙입니다.

TTS

Qwen3-TTS

영어 예고편 대본을 음성 파일로 변환하고 Gradio Audio에 연결합니다.

Fallback

Presentation Safety

각 단계 실패 시 mock, sample, last-success 결과로 데모 흐름을 유지합니다.

구현 순서

GPU를 바로 쓰지 않고, 실패 격리 구조를 먼저 만든 뒤 실제 모델을 하나씩 붙입니다.

1. Pipeline refactor

현재 mock pipeline을 adapter orchestrator로 분리하고 mock은 fallback으로 유지합니다.

2. Runtime modes

presentation/debug 모드, model flags, timeout, output path를 config로 모읍니다.

3. Grounding DINO

최소 설치 경로로 detector adapter를 붙이고 box/list 출력부터 검증합니다.

4. Gemma director

로컬 cache의 Gemma 4 12B IT를 직접 로드하고 JSON schema 출력을 강제합니다.

5. Poster and TTS

빠른 poster 경로와 Qwen3-TTS를 붙이되, 각각 fallback을 유지합니다.

6. Full rehearsal

GPU 3 승인 후 전체 경로를 1회 실행하고 단계별 latency를 기록합니다.

상위 리스크

Grounding DINO 설치 실패

CUDA/PyTorch 조합이나 custom ops가 막히면 detector만 fallback으로 돌리고 발표 흐름은 유지합니다.

VRAM 충돌

Gemma와 poster를 동시에 상주시킬 수 없으면 순차 실행, cache 정리, worker 분리를 적용합니다.

Qwen3-TTS 접근 불명확

1순위는 유지하되, 실제 구현 경로가 막히면 placeholder/lightweight fallback으로 음성 단계를 멈추지 않습니다.

3분 초과

짧은 prompt, 짧은 script, poster 1장, 낮은 step count로 latency를 제한합니다.
